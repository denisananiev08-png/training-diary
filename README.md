# Мой Трек — перенос из Lovable

Статическое PWA без зависимости от Lovable. Данные остаются в существующей Supabase базе через защищённые RPC-функции.

## Развёртывание

Подходит любой бесплатный static hosting: Render Static Site, Vercel Hobby, Cloudflare Pages и др.

Корневая папка — содержимое этого архива. Build command не нужен. Publish directory: `.`

## Первый запуск на iPhone

Приложение не показывает логин. Для привязки устройства используется персональная ссылка вида:

`https://ВАШ-ДОМЕН/#key=ПЕРСОНАЛЬНЫЙ_КЛЮЧ`

Ключ хранится локально на iPhone, а фрагмент URL сразу удаляется из адресной строки. После первого запуска открывается обычный дневник без входа.

Важно: не публикуйте персональный ключ и не добавляйте его в исходники.
