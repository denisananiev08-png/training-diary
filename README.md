# Мой Трек — перенос из Lovable

Статическое PWA без зависимости от Lovable. Данные остаются в существующей Supabase базе через защищённые RPC-функции.

## Развёртывание

Подходит любой бесплатный static hosting: Render Static Site, Vercel Hobby, Cloudflare Pages и др.

Корневая папка — содержимое этого архива. Build command не нужен. Publish directory: `.`

## Первый запуск на iPhone

Приложение не показывает логин. Для привязки устройства используется персональная ссылка вида:

`https://ВАШ-ДОМЕН/#key=ПЕРСОНАЛЬНЫЙ_КЛЮЧ`

Ключ хранится локально на iPhone, а фрагмент URL сразу удаляется из адресной строки. После первого запуска открывается обычный дневник без входа.

Важно: не публикуйте персональный ключ и не добавляйте его в исходники.


## Текущий недельный цикл

- Понедельник — восстановление.
- Вторник — основная Full Body A, 2–3 рабочих подхода без отказа.
- Среда — отдых.
- Четверг — облегчённая Full Body B, 2 подхода и сниженные рабочие веса.
- Пятница — отдых.
- Суббота и воскресенье — индивидуальный бокс, 09:00–10:30, по 90 минут.

После завершения A назначается B на ближайший последующий четверг, после B — A на ближайший последующий вторник. При переносе тип тренировки сохраняется. Просроченный план остаётся доступным до завершения. Завершение бокса не продвигает силовой цикл.

Завершённая история A/B/C сохраняется без миграции. Незавершённые старые шаблоны обновляются при открытии, если в них ещё нет отмеченных выполненных подходов. Старый C больше не предлагается для планирования.

Расписание рассчитывается в `schedule.mjs` из завершённых записей истории. Следующий план сохраняется через существующий защищённый `diary_save_day`. Старый `diary_advance_cycle` (A/B/C) не вызывается; старое состояние `diary_get_cycle` используется только для проверки ключа при привязке устройства. URL Supabase, публичный ключ, ключ устройства и формат существующих записей сохранены. Бокс хранится без силового плана, с метаданными внутри `workout`.

## Проверка

`node --test tests/diary.test.mjs`

Тесты проверяют переходы с сохранением через RPC, даты, архив C, бокс и сбой сохранения. Для проверки реальной синхронизации требуется подключённое устройство с персональным ключом.

Бокс доступен для ручного выбора на любой дате кнопкой «Бокс». Можно записывать третье и последующие занятия в неделю; они не продвигают A/B. При смене типа уже завершённой тренировки или тренировки с выполненными подходами приложение запрашивает подтверждение замены. На одной дате хранится одна запись тренировки.
